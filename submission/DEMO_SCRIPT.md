# SplitNest demo video script (target: 2:45, hard limit 3:00)

**Recorder:** OBS Studio (free) or the Windows Game Bar (Win+Alt+R). Record the browser window at 1080p, microphone on. Upload to Loom or as an unlisted YouTube video and make sure anyone with the link can view it.

**Before recording:** `pnpm install`, then `pnpm dev`. Open http://localhost:5173 in a fresh browser window. Start with no homes (delete `api/.wrangler` while the dev server is stopped if you want a clean database).

| Time | Do                                                                                                        | Say                                                                                                                                                                                                                                                                                           |
| ---- | --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0:00 | Show the "Your homes" page.                                                                               | "This is SplitNest, a shared-expense app. React and TanStack Router on the front, a Hono API on Cloudflare Workers, and D1 SQLite for data."                                                                                                                                                  |
| 0:15 | Type **Flat 4B**, press Create home.                                                                      | "Creating a home calls POST /api/homes. I land on the members page with a helpful empty state."                                                                                                                                                                                               |
| 0:30 | Add **Asha**, **Ben**, **Chitra**.                                                                        | "Members keep the order they were added. That order decides who gets leftover cents."                                                                                                                                                                                                         |
| 0:50 | Open **Bills → New bill**. Click Create bill empty, then type title **Electricity** and amount **10.00**. | "Validation runs in the browser, and the API and the database check it again. The preview shows 3.34, 3.33, 3.33. It uses the same split function as the API, integer cents only, no floats."                                                                                                 |
| 1:20 | Create the bill.                                                                                          | "The bill and its three shares are saved in one transaction."                                                                                                                                                                                                                                 |
